# 스무고개

머릿속에 떠올린 것을 컴퓨터가 예/아니요 질문 스무 번 안에 맞히는 게임.
주제는 '모든 것'(동물·음식·물건·탈것·장소·직업·캐릭터·자연)과 '연예인' 두 가지.

## 구조

| 파일 | 내용 |
| --- | --- |
| `src/data_all.txt` | '모든 것' 질문과 항목 |
| `src/data_celeb.txt` | '연예인' 질문과 항목 |
| `src/engine.js` | 추론 엔진 (질문 고르기, 확률 계산, 학습 반영) |
| `src/ui.js` | 화면 |
| `src/page.html` | 스타일과 기본 마크업 |
| `build.py` | 위 파일을 합쳐 `index.html`을 만든다 |

`index.html`은 빌드 결과물이라 직접 고치지 말고 `src/`를 고친 뒤 `python3 build.py`를 실행한다.

## 데이터 추가하기

```
?키 질문 문장          질문 정의
@태그 태그             아래 항목들의 기본 태그
이름/별명|태그 태그    항목 하나
```

- 적힌 태그는 '예', 안 적힌 태그는 '아니요'로 본다.
- `~태그`는 '그럴 수도 있음', `-태그`는 기본 태그에서 빼기.
- `A`=동물, `P`=식물, `F`=음식, `T`=물건 묶음 태그.
- 빌드할 때 모르는 태그, 이름 중복, 질문으로 구별이 안 되는 항목을 알려 준다.

## 알고리즘

- 후보마다 확률을 두고, 답을 들을 때마다 베이즈 방식으로 갱신한다. 사람이 가끔 잘못 답하는 것(약 6%)을 감안해서 답 하나로 정답이 탈락하지 않는다.
- 다음 질문은 답을 들은 뒤 남는 불확실성(기대 엔트로피)이 가장 작아지는 것을 고른다.
- 확신이 86% 이상이면 20개 전에도 찍고, 20개가 끝나면 상위 후보를 3번까지 찍는다. 그래도 못 맞히면 5개 연장전.
- 이기든 지든 그 판의 답을 브라우저에 기록해 다음 판부터 반영한다 (기기별 저장).
