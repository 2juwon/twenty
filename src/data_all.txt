#   ?키 질문            → 질문 정의
#   @태그 태그 ...      → 아래 항목들의 기본 태그 (다음 @줄까지)
#   이름/별명|태그 ...  → 항목. ~태그 = 그럴 수도, -태그 = 기본 태그 빼기
#   A=동물(liv ani), P=식물(liv plant), F=음식(food), T=물건(thing)
